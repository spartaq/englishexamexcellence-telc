## Implementation Notes

### Recommended Translation Approach
1. Create `src/locales/en.json` and `src/locales/hu.json`
2. Add a `lang` prop to main components that defaults to `'en'`
3. Use language detection via URL path (`/hu/`) or `Accept-Language` header
4. Keep all test content (questions, passages, answers) in English regardless of UI language

### Hungarian Keyword Targets for SEO
- **TELC angol** (TELC English) - ~1,600 monthly searches
- **TELC B2 feladatok** (TELC B2 tasks) - ~800 monthly searches
- **angol vizsga felkészítés** (English exam prep) - ~2,900 monthly searches
- **online angol tanfolyam** (online English course) - ~1,000 monthly searches
- **B1 angol szókincs** (B1 English vocabulary) - ~2,400 monthly searches
